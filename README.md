# ResonanceTestingScripts
Scripts for FNAL CMS OT Plank Resonance Testing

# makePlankJSON.py
Takes CSV file with plank parameters and makes a convenient JSON file for future use/plotting.

# plotPlankHist.py
This makes a histogram of the Young's Moduli of each plank.

# plotPlankScatter.py
This makes a scatter plot of Plank mass (in grams) vs. Young's Modulus.

# plotPlankFreq.py
This makes a scatter plot of Plank mass (in grams) vs. the mean measured frequency of each plank.
